# 範例檔案

這裡的檔案**全部是虛構資料**，給第一次使用的人試用網頁版「個資馬賽克」。打開網頁後，把檔案拖進左邊框框，或按「開啟檔案…」選檔。

| 檔案 | 格式 | 試試看 |
|---|---|---|
| `轉介單.docx` | Word | 姓名、身分證、電話、地址、出生日期都會遮；後面只寫「志明」也會遮；血壓、HbA1c 數字不會遮 |
| `個案名單.xlsx` | Excel | 表頭是「姓名」「身分證號」「手機」「地址」的整欄都遮；按「存成 Excel 可開的檔案」存回去 |
| `個案名單.csv` | CSV（UTF-8） | 和上面同一份名單，CSV 格式 |
| `訪視紀錄.txt` | 文字檔（UTF-8） | 「兒子黃建國」沒有稱謂、沒有標籤，預設抓不到；在「這份資料裡有誰的名字」填「黃建國」就會遮 |
| `舊公文-Big5.txt` | 文字檔（Big5） | 舊系統匯出的 Big5 編碼也讀得懂，不會變亂碼 |
| `回覆範例-換回真名用.txt` | 文字檔（UTF-8） | 先在「① 遮蔽個資」放入 `轉介單.docx`，再到「② 把代號換回真名」放入這個檔，代號會換回陳志明、陳美玲和手機號碼 |

範例檔由 `scripts/build_examples.py` 產生，只用 Python 標準函式庫：

```bash
python scripts/build_examples.py
```
